# Explicit Scope & Known Limitations (v3.10.1)

1. **Enforcement Boundary**: Apodictic enforces invariants on traffic routed through `apodictic-sdk@3.10.1`, `apodictic-mcp-verifier@3.10.1`, `wrap-odoo`, or the PostgreSQL wire proxy (`apodictic_pg_proxy`). Direct database connections bypassing the gateway require database-level network/credential isolation.
2. **Database Concurrency & Real PostgreSQL 17 CI Verification**: Concurrent TCP solvency contention is verified at both 16 workers (`evidence/pg17-concurrency-receipt.json`: `3` allowed / `13` blocked with `SQLSTATE 40001` / `0` overdrafts) and 64 workers (`evidence/adversarial-redteam-receipt.json`: `5` allowed / `59` blocked with `SQLSTATE 40001` / `0` overdrafts) against the compiled Rust `apodictic_pg_proxy` binary. Furthermore, the public GitHub Actions CI suite executes a dedicated `verify-live-postgres17-and-redteam` job against a real `postgres:17` Docker service (`64` concurrent real TCP `pg.Pool` connections with `SELECT ... FOR UPDATE`, `32` concurrent `AFTER UPDATE` PL/pgSQL trigger `SAVEPOINT` rollbacks, and `ON DELETE CASCADE` protection) alongside embedded PostgreSQL 18.7 (`@electric-sql/pglite`); multi-region HA clusters remain deployment-specific.
3. **Formal Model & Multi-Engine Red-Team Scope**: `formal-specifications.smt2` (`QF_LRA`) models financial reserve floors, 24-hour velocity caps, double-entry conservation, and tax parity. Both the WebAssembly verifier (`z3_wasm_verifier.mjs`), standalone Python enclave (`standalone_z3_enclave.py`), and native Rust compiler (`apodictic-symbolic-sql` via `sqlparser 0.64`) pass `40/40` cross-engine red-team bypass checks (comment-split DDL, zero-width Unicode smuggling, BOM characters, stacked SQLi, `pg_read_file`/`lo_export`/`dblink`, double-negation debits, constant arithmetic folding, tautology `WHERE` predicates, CTE deletes, and `DO $$ EXECUTE $$` obfuscation). Inside `apodictic_pg_proxy`, `--savepoint-mode` wraps upstream transactions in live `SAVEPOINT` / `ROLLBACK TO SAVEPOINT`.
4. **External Validation**: Independent third-party penetration testing, blind external test corpora, SOC 2 Type II certification, and bare-metal Linux `/dev/kvm` Firecracker hypervisor escape testing remain external-infrastructure milestones.
